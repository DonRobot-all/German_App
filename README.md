# Немецкие слова

Мобильное приложение (Flutter, Android) для изучения и повторения немецких слов.

Что есть сейчас (итерация 1):
- наборы слов (создать, переименовать, удалить);
- слова с артиклем (der/die/das), множественным числом, несколькими вариантами перевода, примером и заметкой;
- глаголы с формами: Präsens (er/sie/es), Präteritum, Perfekt;
- кнопки ä ö ü ß при вводе слова;
- локальная база SQLite (работает без интернета).

## Получить APK через GitHub (без установки Flutter)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository, можно приватный).
2. Загрузите в корень репозитория **содержимое** этой папки (не саму папку): `pubspec.yaml`, `lib`, `.github`, `.gitignore`, `README.md`.
   Способ: в репозитории Add file → Upload files, перетащите файлы и папки, нажмите Commit changes.
   Если папка `.github` не загрузилась (она скрытая), создайте файл вручную: Add file → Create new file, в поле имени введите
   `.github/workflows/build-apk.yml` и вставьте туда содержимое этого файла.
3. Откройте вкладку **Actions**. Сборка запустится сама (5–10 минут). Если нет, выберите Build APK → Run workflow.
4. Когда рядом с запуском появится зелёная галочка, откройте его и внизу в разделе **Artifacts** скачайте `german-words-apk`.
5. Распакуйте архив, перекиньте `app-release.apk` на телефон и установите (разрешив установку из неизвестных источников).

Каждый раз, когда вы загружаете обновлённые файлы, GitHub собирает новый APK.
Если сборка завершилась красным крестиком, откройте запуск, скопируйте текст ошибки и пришлите мне.

## Запуск на своём компьютере (по желанию)

    flutter create --platforms=android --org com.example german_words
    # скопировать pubspec.yaml и папку lib в созданный проект, удалить test/widget_test.dart
    flutter pub get
    flutter run
